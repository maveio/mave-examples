# Mave examples

Open-source examples that show what you can build with [Mave](https://www.mave.io).
Use them for inspiration, extend them into your own platform or host them as they are.

## Starter projects

Complete projects you can run, restyle and put online.

| Starter | What it is |
| --- | --- |
| [Video library](starters/video-library/) | A browsable video library with categories, folders, search, a watch page with transcript and an "Up next" queue. Plain HTML, CSS and JavaScript, no build step. |

## Mave 101

The `lessons` and `final` folders contain the lessons made for [the guide](https://mave.io/learn/mave-101/) we've created on how to integrate mave.io into your own website.

### Technologies used

- HTML
- Tailwind CSS
- JavaScript
- mave.io

### Getting started

To run the lessons locally, follow these steps:

1. Clone the repository: `git clone https://github.com/maveio/mave-examples.git`
2. Navigate to the project directory: `cd mave-examples`
3. Open the `index.html` file of the lesson you want to start in a web browser.
